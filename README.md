# catalyst

**医療・介護の多職種のあいだで、「一方は分かっているが、もう一方は分かっていない前提」を、伝える前と伝える最中に埋めるWebアプリ**です。
Googleハッカソン（DevFest GDGoC Japan Hackathon 2026、提出：2026年11月10日 19:00）のために作っています。

使い方は2つです。

- **伝える前に確かめる**：医師が薬剤師への指示「チューブを2本持ってきてください」を書くと、「なぜ2本なのか？」と、薬剤師が分からなそうな点を挙げます。医師は理由を書き足してから伝えます。AIは根拠を書きません。
- **会話を聞く**：医師が患者に「NSAIDsを毎食後に服用してください」と話すと、患者の手元の画面の下に「NSAIDsは分かりますか？」とそっと出ます。「いいえ」と答えた言葉は画面の上のリストに残り、患者は好きなときに医師に直接聞けます。AIは言葉の意味を説明しません（医療では、誤った答えが命に関わるおそれがあるため）。
