# catalyst

**医療の多職種間で、「一方は分かっているが、もう一方は分かっていない前提」をAIが予測し、伝える前に埋めるWebアプリ**です。
Googleハッカソン（発表日：2026年11月10日）のために作っています。

例：医師が「チューブを2本持ってきてください」と入力すると、AIが「薬剤師さんは、なぜ2本なのか分からないかもしれません。理由を書き足しますか？」と知らせます。
