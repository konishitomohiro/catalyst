# Zureless

**医療・介護の会話の中の「分からない」に、聞いている人がその場で気づけるWebアプリ**です。名前は「認識のズレ（Zure）をなくす（less）」という意味です。
チーム Catalyst が、DevFest GDGoC Japan Hackathon 2026（カテゴリ：医療・福祉）のために作りました。

- **アプリの URL**：https://prototype-212201344730.asia-northeast1.run.app （ログイン不要。パソコンと Android の Chrome がおすすめ）
- **使い方**：聞く人が手元のスマホで会話を聞き取ります。医師が「NSAIDsを毎食後に服用してください」と話すと、患者の画面の下に「NSAIDsは分かりますか？」と出ます。「いいえ」と答えた言葉は画面の上のリストに残り、患者は会話の区切りで医師に直接聞けます。会話は LINE のように話す人（左）と聞く人（右）の吹き出しに分かれ、終えた会話は端末の中にだけ履歴として残ります。
- **AIは答えない**：AI（Gemini）は分かりにくそうな言葉を見つけるだけで、言葉の意味や答えは書きません。医療では、誤った答えが命に関わるおそれがあるためです。答えは話した本人に聞きます。
