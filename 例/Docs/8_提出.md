### 提出のしかた

1. 提出物を入れた Google ドライブのフォルダを作る。
2. フォルダを **「リンクを知っている全員が閲覧可」** にする（開けないと失格のおそれ）。
3. 会場ごとの Google フォームに、**GitHub の URL** と **Drive フォルダの URL** を出す。

## 気をつけること（このアプリ固有）

1. **iPhone の Safari で動かすと、文字起こしは Apple の音声認識になる。** 他社の AI を前面に出さない決まりと、「Google技術の活用」の評価の両方から、デモは **Chrome（Google の音声認識）** で行うか、文字起こしも Gemini（Google）に置き換えるのが安全。話者分離の試作（Gemini に音声を送る）とも合う。
2. **Gemini は Vertex AI 経由で呼ぶ。** 配られる Google Cloud クレジット（1チーム20ドル）は、Google AI Studio の API キーには使えない。✅ 2026-11-06 に Vertex AI 経由に切り替えた。
3. **費用事故を防ぐ。** 予算アラート（10・15・20ドル）、使わないリソースを止める、API の利用制限。デプロイ URL を審査員に見せる場合は、リージョナルデイ（11/14）まで動かし続ける。
4. **個人のリポジトリから運営のリポジトリへ移す。** 運営のリポジトリでは GitHub Actions が使えない見込み。
