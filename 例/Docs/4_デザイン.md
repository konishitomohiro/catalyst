## ユニバーサルデザインの方針（2026年11月6日決定）

ユニバーサルデザインを適用する。以下を方針とする。

### なぜこのアプリにユニバーサルデザインが要るか

端末を持つ受け手は、医師・患者・薬剤師・看護師・介護者の誰でもなりうる。たとえば次のような人が使う。

- 小さい文字が読みにくい高齢の患者、老眼の介護者
- 手がふるえる人、片手がふさがっている人（もう片方で患者を支えている など）
- 色の見分けがつきにくい人（日本の男性の約20人に1人）
- 耳が聞こえにくい人（話を聞き逃しても、画面の文字で追える）
- 日本語が母語でない人、専門用語にまったくなじみがない人
- 緊張していたり、体調が悪かったりして、考える余裕がない人

### 7つの原則と、このアプリでやること

| 原則 | このアプリでやること |
| --- | --- |
| 1. 誰でも同じように使える | 職種で画面を変えない。どの職種が受け手でも、同じ画面・同じ操作にする |
| 2. 使い方を選べる | 端末の文字サイズ設定に合わせて文字が大きくなる。縦向き・横向き、スマホ・パソコン（Zoom 用）のどれでも使える |
| 3. 簡単で直感的 | 1つの画面でやることを1つに絞る。帯で聞くのは1回に1語。操作は「はい／いいえ」と「チェック」だけ |
| 4. 必要な情報がすぐ分かる | 色だけで区別しない（チェック済みは ✓・取り消し線・位置でも示す）。音だけに頼らない |
| 5. 間違えても大丈夫 | チェックは外せる（決定済み）。「はい／いいえ」も押し間違えたときに取り消せるようにする。自動で消えるものは作らない |
| 6. 体の負担が少ない | 押す場所は大きく（44×44pt 以上）、間をあける。よく押すボタンは親指が届く画面の下側に置く |
| 7. 使いやすい大きさと空間 | 本文の文字は 18px 以上、帯の「〇〇は分かりますか？」は 20px 以上。文字と背景のコントラストは 4.5:1 以上（WCAG 2.2 AA） |

### 具体的な決まり

**文字**

- 本文 18px 以上、質問リストと帯の言葉 20px 以上。端末の文字サイズ設定に合わせて大きくなるようにする（px ではなく rem で指定）。
- 画面の文言は短く、やさしい日本語にする。画面の文言の漢字には、ふりがなを付ける。
- 行間はゆったり（1.6 倍以上）。

**色**

- 色3つ（色の見分けにくさがあっても区別しやすい組み合わせ）：
  - 基本色：濃い青（ボタン・選んでいる職種）
  - 注意の色：オレンジ（また出た言葉を光らせる）。赤と緑の組み合わせは使わない。
  - 背景と文字：白地に濃いグレーの文字。帯は濃いグレーの地に白い文字。
- コントラストは、文字 4.5:1 以上、ボタンの枠やアイコン 3:1 以上。

**操作**

- 押す場所は 44×44pt 以上。「はい」と「いいえ」は離して置き、押し間違いを防ぐ。
- 「はい」と「いいえ」は色と形の両方で区別する（例：「いいえ」は塗りつぶし、「はい」は枠だけ）。
- 時間制限を作らない。帯の「分かりますか？」は、答えるまで残る（決定済み）。

**動き**

- 光らせる・スクロールなどの動きは控えめにする。端末で「視差効果を減らす」を設定している人には動きを止める。

**音・読み上げ**

- 画面読み上げ（iPhone の VoiceOver など）で、帯に新しい「分かりますか？」が出たことを伝える。
- 音を鳴らす場合も、必ず画面の表示と一緒にする（音だけで知らせない）。

### 今の決定とぶつかるところと、その対応

- **質問リストのチェックが、親指の届きにくい画面上部にある**（原則6）→ チェックの押せる範囲を行全体に広げる。リストの場所は変えない。
- **「はい／いいえ」を押し間違えても取り消せない**（原則5）→ 答えたあと数秒、帯に「取り消す」を出す。

### まだ決めていないこと

- 帯や質問リストに出る言葉（AIが見つけた言葉。例：褥瘡）にも、ふりがなを付けるか。付けるなら読みをどう用意するか
- 「取り消す」を出しておく秒数

## 決まった部品

### 「分かりますか？」の出し方（2026年11月6日決定）

動画アプリやSNSで、再生中の動画を画面の下にしまったときの「ミニプレーヤー」のような形にする。

- メインの画面（質問リストなど）は、下の角を丸くして少し上に縮める。
- その下にできた暗い色の帯に、「〇〇は分かりますか？」を1件ずつ出す。帯の中に「はい」「いいえ」を置く。
- 帯はメインの画面を覆わない。B は会話を聞きながら、好きなときに答えられる。
- B が答えないうちに次の「分かりますか？」が出たら、前のものを消さずに残して並べる。

- 並べ方：帯の中で**横に並べ、スワイプで切り替える**。帯の高さは変えない。
  - いちばん古いものを手前に出す。
  - 答えていない件数を帯の中に出す（例：「あと2件」）。
