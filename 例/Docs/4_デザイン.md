# デザイン

2026年11月6日更新（MVP対面仕様に合わせた設計）。

| 項目 | 決めたこと |
| --- | --- |
| めざす感じ | 清潔感と安心感があり、対面時に受け手が片手でも迷わず操作できるシンプルなUI |
| 画面ごとの仕事 | 1画面完結。上部で質問リストを管理し、中央でAIの「分かりますか？」確認を受け、下部で発言を入力する |
| 色3つ | ベース（白・薄灰 #f8fafc / #0f172a）、メイン（信頼の青 #2563eb）、アクセント（質問・気付きの琥珀・緑 #d97706 / #059669） |
| 部品表 | 職種選択ヘッダー、質問リスト（iOSリマインダー風、完了が上・未完了が下）、AI確認カード（はい／いいえ）、発言入力フォーム |
| やらないこと | 複雑な画面遷移、AIによる自動回答、システムによる質問リストの自動削除 |

## 画面一覧

### 1. 対面MVPメイン画面（1画面）
- **ヘッダー部**: 送り手職種（医師/患者/薬剤師/看護師/介護者）と受け手職種（薬剤師/患者）の選択。
- **質問リスト部（画面上部・スクロール可）**:
  - 上側: 質問済み（チェック済み）の項目（グレーアウト表示）。
  - 下側: まだ聞いていない項目（未チェック、手元で見えやすい位置）。
  - 各項目にチェックボックスがあり、タップで完了/未完了を切り替え可能。
- **AI確認部（画面中央）**:
  - 発言から検出された用語について「〇〇は分かりますか？」とカード表示。
  - 「はい」ボタン: 理解しているためリストに追加せず閉じる。
  - 「いいえ」ボタン: 質問リストの最下部（見えやすい側）に追加。
  - すでに質問リストにある語の場合: 「〇〇はすでに質問リストにあります（質問済み／未質問）」と通知。
- **会話入力部（画面下部）**:
  - 送り手の発言を文章で入力するテキストエリアと「送信」ボタン。
  - 発言履歴のタイムライン表示。
