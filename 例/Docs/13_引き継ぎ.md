### 調べる順番（案）

1. `git pull` して `npm run eval` を実行し、「Google からのエラー：」の元の文を見る（11月7日に、元の文を出すように直した）。
2. アカウント：`gcloud auth list`。ADC（アプリが使う認証）のアカウントは、`gcloud auth application-default print-access-token` のトークンを tokeninfo で確かめる。
3. 権限：そのアカウントが `zentei-app-1106-4528` で `roles/owner` か `roles/aiplatform.user` を持っているか（`gcloud projects get-iam-policy`）。
4. 課金：`gcloud billing projects describe zentei-app-1106-4528` で、課金アカウントがつながっているか。
5. API：`gcloud services list --enabled --project zentei-app-1106-4528 --filter=aiplatform`。
6. モデルと地域：ADC のトークンで Vertex AI の `generateContent` を直接呼び、元のエラーを見る。モデル名（`gemini-3.8-flash` / `gemini-3.5-flash-lite`）と地域（`global` / `asia-northeast1` / `us-central1`）を変えて試す。
7. ADC の quota project：`gcloud auth application-default set-quota-project zentei-app-1106-4528`。
