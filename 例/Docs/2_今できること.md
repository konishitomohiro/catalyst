## MVPで作る機能

対面の流れ（方向タブ 7章）を、音声入力で作る。

✅ は試作で作り、自動テストと、偽の音声・偽の AI の答えを差し込んだブラウザで動きを確かめたもの。**本物の Gemini と本物の声での確認はまだ**（直すことタブ #4）。

- [x] ホーム画面で、利用を始めるときに送り手と受け手の職種を1回選ぶ（医師・患者・薬剤師・看護師・介護者）
- [x] 送り手の話を文字起こしする（ブラウザの音声認識。精度はあまり良くない）
- [x] AIが文字起こしから「理解するのに前提が必要な用語」を見つける（観点リストが決まるまでは AI の判断だけ）
- [x] 受け手に「〇〇は分かりますか？」と出し、はい／いいえで答えてもらう（画面下部の帯。横に並べてスワイプ）
- [x] 「いいえ」の語を質問リストのいちばん下に足し、画面上部に出す（スクロールで全部見られる）
- [x] 一度答えた語は聞き直さない。質問リストにある語なら、その項目と状態を見せる
- [x] 質問できた項目に受け手がチェックをつけられる（行全体が押せる）
- [x] チェックを外せる。外した項目は下側（まだ聞いていない側）へ戻す
- [x] チェックをつけた項目をリストの上のほうへ移す。チェック済みも消さずに残す
- [x] ふりがな（画面の文言と、AIが見つけた言葉）
- [x] 答えたあと5秒「取り消す」を出す
- [x] ホームに戻るとき、リストが消えることを確かめる
- [ ] 声で2人を分ける（直すことタブ #6）

## 扱わない範囲

| 扱わないもの | 理由 |
| --- | --- |
| 処方・診断が医学的に正しいかの判断 | AIは専門の正誤を保証できない。判断は医療者がする |
| 電子カルテ・処方システムとの連携 | 締め切りまでに作れず、デモにも要らない |
| 実在の患者の個人情報の保存（会話履歴は保存する〔11月8日決定〕が、発表では架空のデータだけを使う） | 発表用なので、架空のデータだけを使う |
| ログイン・アカウント管理 | デモに要らない |
| AIが受け手の疑問に答える（語の意味の説明など） | 誤った答えが命に関わるおそれがある。答えは送り手に直接聞く |
| 送り手の確認の、受け手側の画面（質問リスト・受け手への共有・送信） | 2026年11月8日に、送り手に補足を促す画面だけ作ると決めたため。文章は、いつもの方法で送る |
| 会話の流れでの文章入力 | 会話は音声入力だけにしたため（文章入力は「送り手の確認」だけ） |
| システムが会話のキリを判断する・質問を促す | キリは人が決める。システムは割り込まない |

## 完了の条件

**案**（2026年11月6日。人が確かめて決める）。提出（11月10日 19:00）の時点で、次がすべてできていれば完成とする。

1. Cloud Run の URL を、受け手のスマホ（デモで使う端末とブラウザ）で開ける。
2. ホームで職種を選び、話す人が架空の会話を話すと、文字になる。
3. 前提が要りそうな言葉が、帯に「分かりますか？」として出る（本物の Gemini で）。
4. 「いいえ」の言葉が質問リストに入り、印をつけると上へ移る。
5. AI評価テスト（`npm run eval`）が目安（10件中8件以上）を超える。
6. コード側のチェック（`npm run check`）がすべて通る。
7. AIが言葉の意味や答えを画面に出さない（コードで守る制約が、本物の Gemini でも効いている）。
