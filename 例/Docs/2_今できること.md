## MVPで作る機能

対面の流れ（方向タブ 7章）を、音声入力で作る。

- [ ] ホーム画面で、利用を始めるときに送り手と受け手の職種を1回選ぶ（医師・患者・薬剤師・看護師・介護者）
- [ ] 送り手の話を文字起こしする
- [ ] AIが文字起こしから「理解するのに前提が必要な用語」を見つける（観点リストが決まるまでは AI の判断だけ）
- [ ] 受け手に「〇〇は分かりますか？」と出し、はい／いいえで答えてもらう
- [ ] 「いいえ」の語を質問リストのいちばん下に足し、画面上部に出す（スクロールで全部見られる）
- [ ] 一度答えた語は聞き直さない。質問リストにある語なら、その項目と状態を見せる
- [ ] 質問できた項目に受け手がチェックをつけられる（iOS のリマインダーのような形）
- [ ] チェックを外せる。外した項目は下側（まだ聞いていない側）へ戻す
- [ ] チェックをつけた項目をリストの上のほうへ移す。チェック済みも消さずに残す

## 扱わない範囲

| 扱わないもの | 理由 |
| --- | --- |
| 処方・診断が医学的に正しいかの判断 | AIは専門の正誤を保証できない。判断は医療者がする |
| 電子カルテ・処方システムとの連携 | 締め切りまでに作れず、デモにも要らない |
| 実在の患者の個人情報の保存 | 発表用なので、架空のデータだけを使う |
| ログイン・アカウント管理 | デモに要らない |
| AIが受け手の疑問に答える（語の意味の説明など） | 誤った答えが命に関わるおそれがある。答えは送り手に直接聞く |
| 文章での入力 | MVPは音声入力だけにしたため |
| 送り手に補足を促す画面 | MVPを対面の流れ（受け手が端末を持つ）に絞ったため |
| システムが会話のキリを判断する・質問を促す | キリは人が決める。システムは割り込まない |
